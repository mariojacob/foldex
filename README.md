## About Foldex

Foldex is a desktop application for teams and solo professionals who want to
create standardized project folder structures without repetitive manual setup.
Reusable templates, smart parameters, live previews, and safe generation keep
projects consistent while project data stays on the local machine.

## Highlights

- Build reusable visual templates for folders and files.
- Generate complete project structures with one click.
- Use text, number, date, list, and user parameters.
- Preview generated paths before writing anything.
- Include seed files in reusable templates.
- Import and export templates as JSON.
- Keep templates, settings, history, and project data locally.
- Unlock optional workflow automation with Foldex Pro.

### Windows

1. Download the Windows installer from the latest release.
2. Run `Foldex-Windows-Setup-{version}.exe`.
3. Follow the setup wizard.

Running a newer installer updates an existing Foldex installation while local
application data remains in the user's application-data directory.

## Updates

Foldex checks for new stable releases at startup at most once every 24 hours.
A manual check is also available under `Settings -> Updates`.

When a newer version is available, Foldex offers to open the corresponding
GitHub release. The application never downloads or starts an installer
automatically.

If the primary GitHub repository address becomes obsolete, Foldex can retrieve
the current release API address from its independent update endpoint.

## Privacy and Network Access

Project structures, templates, settings, and generated files remain local.
Foldex uses network access only when required for:

- checking for application updates;
- activating or periodically verifying an optional Foldex Pro license; and
- opening user-requested external purchase or release pages.
