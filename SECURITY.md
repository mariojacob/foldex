# Foldex Security Policy

## Supported Versions

Security fixes are provided for the latest stable Foldex release. Users should
upgrade to the newest version before reporting an issue that may already have
been resolved.

| Version                      | Supported |
| :--------------------------- | :-------- |
| Latest stable release        | Yes       |
| Older releases               | No        |
| Preview or prerelease builds | No        |

## Scope

The policy covers:

- official Foldex binaries published by `mariojacob/foldex`;
- the Windows installer;
- update checking and release-link validation;
- local data handling; and
- Foldex Pro license activation and verification.

Third-party services and vulnerabilities that do not affect Foldex should be
reported directly to their respective operators.
